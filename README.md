# 🎓 Exam Seating Visualizer

## 📌 Overview

An interactive web application that simulates **exam hall seating arrangements** using a backtracking algorithm (N-Queens concept).

The system ensures that no two students are placed in positions where cheating is possible (same column or diagonals).

---

## 🚀 Features

* 🎯 Conflict-free student placement
* ⚡ Real-time visualization
* 🎛 Adjustable animation speed
* 📊 Live stats (students placed, status)
* 🧠 Backtracking-based solution

---

## 🧠 Algorithm Used

* **Backtracking (N-Queens approach)**
* Try → Validate → Place → Backtrack

---

## ⏱ Time Complexity

* **O(N!)** (worst case)

---
